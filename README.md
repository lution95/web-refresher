## Reflection

This assessment helped me revisit the HTML5, CSS and JavaScript skills from Web Development I. I found organising content with semantic HTML elements, such as header, main, section and footer, straightforward. Keeping the HTML, CSS and JavaScript in separate files also made the project easier to understand.

The most challenging part was making the layout work well on both phone and desktop screens. Adjusting spacing and using media queries required careful attention. Connecting JavaScript events to changes on the page was another area that needed practice.

During Web Development II, I would like to improve my JavaScript debugging skills, especially using browser developer tools to understand errors and check DOM interactions. My next step is to practise small interactive features and test them regularly at different screen sizes.
